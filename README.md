# 🎣 Fish Hunter

텍스트 기반 물고기 크기 맞추기 게임!  
[`drawingletters`](https://pypi.org/project/drawingletters/) 모듈을 활용해 ASCII 아트 물고기를 출력합니다.

---

## 🎮 게임 방법

1. 게임을 실행하면 난이도를 선택합니다.
2. 물고기가 나타나면 크기를 숫자로 입력하세요.
3. 정답을 맞추면 물고기를 획득하고 점수가 올라갑니다!
4. `q`를 입력하면 게임이 종료되고 최종 결과를 확인할 수 있습니다.

---

## 🐟 게임 예시

```
🌊 물고기가 나타났다!
물고기 크기를 맞혀보세요 (3~10, 그만하려면 q): 5
✅ 정답!! 물고기 획득!
><(((((º>
현재 점수: 1 / 1
```

---

## ⚙️ 난이도 시스템

| 난이도 | 크기 범위 | 힌트 |
|--------|----------|------|
| 쉬움   | 3 ~ 6    | ✅ 있음 (더 크게 / 더 작게) |
| 보통   | 3 ~ 10   | ❌ 없음 |
| 어려움 | 1 ~ 15   | ❌ 없음 |

---

## 🏆 점수 시스템

게임 종료 시 총 도전 횟수, 획득한 물고기 수, 정답률을 표시합니다.

| 획득 수 | 평가 |
|--------|------|
| 0마리   | 😢 아쉽네요! 다음엔 꼭 잡아봐요! |
| 1~3마리 | 🐟 더 연습해봐요! |
| 4~7마리 | 🎣 꽤 능숙한 낚시꾼! |
| 8마리~  | 🏅 최고의 낚시왕!! |
